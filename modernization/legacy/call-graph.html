Every edge is either PROVEN (static, cited file and line) or CANDIDATE (dynamic or inferred). The two are never shown in one list: each table and the diagram show one certainty at a time. A dynamic site with no settled target is an open ask, not an edge.

Program-to-program diagram

Estate members only (system routines omitted; they are in the Program to program tab). Click a program to highlight its edges and list them below; click it again or press Escape to clear.

Program to program

COBOL CALL, CICS LINK and CICS XCTL. HLASM and PL/I members are leaf nodes (target is leaf-HLASM / leaf-PL/I). Targets marked runtime or not-in-estate are system routines (LE, MQ, DL/I) the repository does not supply.

Job to step to program

Every EXEC of every scanned JCL job, with launcher steps (IKJEFT01, DFSRRC00) unwrapped to the program they run where a card names it.

Program to dataset, table, queue or map

Direction is reads, writes or updates (REWRITE, DELETE, SQL UPDATE/DELETE, DL/I REPL/DLET). For maps, writes = SEND MAP and reads = RECEIVE MAP.

Programs sharing copybook layouts

Copybooks copied by two or more programs. Every COPY statement is a static, cited fact, so all rows are PROVEN (static, cited file and line). Known gap: the scanner does not read COPY with a quoted member name (COPY 'CSSTRPFY', COPY 'CSUTLDWY'); those copies are not in this table, see Unreferenced members and INTAKE.md.

By copybook

Transaction id to initial program

From the DEFINE TRANSACTION entries of the CSD files under app/csd and app/app-*/csd.

Scheduler order

From app/scheduler (CA 7 and Control-M exports): which table orders which job, and which job runs before which.

Unscheduled JCL jobs

Jobs that no table in app/scheduler orders. How they are run is not in the repository.

Open asks

Dynamic sites whose target the sources do not settle. Questions with an owner placeholder; nothing was guessed.

Uncalled programs

No PROVEN inbound edge from a job step, a transaction or another program.

Unreferenced members

Catalogued members that no scan result names. The last column is a plain text search of app/ for the name: a hit means the source mentions it where the scanner does not read it (for example assembler macro calls).
