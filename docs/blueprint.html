Method and thresholds

Scope. Every file under app/ except data files (data/, *.dat), the catalog listing (catlg/, used only to corroborate dataset types) and documentation (*.md, *.txt, .gitkeep). Component type comes from the file extension (cpy-bms/ copybooks are typed “BMS Copybook”).

LOC = non-blank, non-comment lines. COBOL, copybooks and DCLGEN: fixed format, * or / in column 7 (and *>) are comments, a line whose columns 8–72 are blank is blank (tabs expanded to 8). JCL/PROC: //* is a comment. PL/I, DDL, control cards: /* … */ (and -- for SQL) are comments. Assembler, macros, BMS, DBD/PSB: * or .* in column 1. CSD/scheduler: lines starting with *.

Complexity. Decision points (DP) are counted on code lines with literals removed: COBOL IF, EVALUATE, WHEN, PERFORM, GO TO, EXEC CICS, EXEC SQL, EXEC DLI (END-IF etc. excluded); PL/I IF, SELECT, WHEN, DO WHILE/UNTIL, GO TO, ON, EXEC CICS/SQL; Assembler conditional branch / AIF/AGO opcodes. Cyclomatic proxy = DP + 1. LOC points: <500 = 1, 500–1500 = 2, >1500 = 3. DP points: <50 = 1, 50–150 = 2, >150 = 3. Score = LOC points + DP points (2–6): 2–3 Low, 4 Medium, 5–6 High.

Batch vs Online. COBOL/PL/I/ASM with EXEC CICS → Online; else invoked by JCL (EXEC PGM=, TSO RUN PROGRAM() under IKJEFT01, IMS DFSRRC00 PARM='DLI|BMP,pgm,psb') → Batch; else classified from static callers (CALL 'X', CICS LINK/XCTL PROGRAM('X')): any batch caller → Batch, only online callers → Online; otherwise Batch.

Data. DB2 tables: names after FROM/INTO/UPDATE/JOIN in EXEC SQL blocks, CREATE TABLE/VIEW in DDL, control cards and in-stream DB2 SYSIN, and EXEC SQL DECLARE … TABLE in DCLGENs; host variables, SYSIBM.* and SQLCA are excluded and unqualified names are folded onto their qualified form. IMS: DBDs (DBD NAME=,ACCESS=), PSBs (PCB TYPE=,DBDNAME=), programs with EXEC DLI or CALL 'CBLTDLI'/'PLITDLI'. GDGs: IDCAMS DEFINE GDG/GENERATIONDATAGROUP plus every DSN=base(+n|0|-n). Datasets: unique DSNs from JCL/PROC DD statements, IDCAMS DEFINE CLUSTER/AIX/PATH and CSD DEFINE FILE … DSNAME() (JCL symbols such as &HLQ resolved from SET/PROC). GSAM = DD matches a GSAM DBD DATASET DD1/DD2 in an IMS step; VSAM = IDCAMS cluster/AIX/PATH definition, CICS file, COBOL ORGANIZATION INDEXED/RELATIVE on the step's DD, LISTCAT cluster, IMS HIDAM/INDEX DBD dataset or a .VSAM/.KSDS/.ESDS/.RRDS qualifier; everything else is QSAM. Temporary (&&), DUMMY, SYSOUT, load/PDS libraries and member references are excluded.

All figures are produced by static pattern matching; dynamic CALL targets, PROC symbolic overrides and run-time dataset names are not resolved.
