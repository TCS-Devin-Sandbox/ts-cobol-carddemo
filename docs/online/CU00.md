# CU00 — List Users

Source: [COUSR00C](../../app/cbl/COUSR00C.cbl), map [COUSR00 / COUSR0A](../../app/bms/COUSR00.bms).
CA00 option 1 opens `/admin/users`. The browser route and `GET /api/admin/users`
require the E2 admin role. See also [CU01 Add](CU01.md), [CU02 Update](CU02.md)
and [CU03 Delete](CU03.md).

| COBOL paragraphs | Port and test trace |
|---|---|
| MAIN-PARA, RETURN-TO-PREV-SCREEN | Admin JWT replaces COMMAREA; initial browse and PF3 to CA00. `UserAdminIntegrationTest.MAIN_PARA_*`; UI CA00 entry / PF3 and direct-entry guard. |
| PROCESS-ENTER-KEY | Start at the first key at or after the entered ID (blank means beginning); the first populated selection in screen order wins. U/u routes to CU02, D/d to CU03, other values report the source message. API browse and UI selection tests. |
| PROCESS-PF7-KEY, PROCESS-PF8-KEY, PROCESS-PAGE-FORWARD, PROCESS-PAGE-BACKWARD | Browse in pages of ten with the source messages at either boundary. UI paging test; API `CU00_PROCESS_ENTER_KEY_PROCESS_PF7_KEY_PROCESS_PF8_KEY_STARTBR_READNEXT_READPREV_ENDBR`. |
| STARTBR-USER-SEC-FILE, READNEXT-USER-SEC-FILE, READPREV-USER-SEC-FILE, ENDBR-USER-SEC-FILE | Stateless queries seek inclusively at `startId`, exclusively at `after` (last key) or `before` (first key). Backward results are displayed in ascending order. A forward lookahead detects the last page. API browse test. |
| POPULATE-USER-DATA, INITIALIZE-USER-DATA | Return ID, first name, last name and type only. A successful page change replaces the rows and clears the previous selections. API browse and UI paging tests. |
| SEND-USRLST-SCREEN, RECEIVE-USRLST-SCREEN, POPULATE-HEADER-INFO | React table and search/selection inputs, shared header and PF-key bar. UI header, selection and paging tests. |

**Deviations.** SQL uses PostgreSQL's deterministic C collation, not host VSAM's
EBCDIC collation. Data is rendered compactly (no padded or empty rows). The
browse retains a search lower bound until Enter starts a fresh browse; this
substitutes explicit cursor state for the COBOL saved first/last keys and
end-of-file flags. CU02/CU03 return to a fresh list rather than reusing terminal
buffers. The header uses the browser clock and the common online layout.
