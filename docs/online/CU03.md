# CU03 — Delete User

Source: [COUSR03C](../../app/cbl/COUSR03C.cbl), map [COUSR03 / COUSR3A](../../app/bms/COUSR03.bms).
CA00 option 4 or CU00's D selection opens `/admin/users/delete`. The latter
auto-fetches the selected user.

| COBOL paragraphs | Port and test trace |
|---|---|
| MAIN-PARA, RETURN-TO-PREV-SCREEN | Admin JWT; selected key from CU00 carries in browser route state. PF3 returns to caller; PF12 exits to CA00. API `MAIN_PARA_*`; UI CU00 selection and CU03 tests. |
| PROCESS-ENTER-KEY, READ-USER-SEC-FILE | Enter fetches `GET /api/admin/users/record?userId=…`; key required, missing row uses the source error, successful read fills protected fields and shows the PF5 prompt. API `CU02_CU03_PROCESS_ENTER_KEY_READ_USER_SEC_FILE_never_returns_password`; UI CU03 fetch. |
| DELETE-USER-INFO, DELETE-USER-SEC-FILE | PF5 submits DELETE on the same resource. A single keyed delete replaces READ UPDATE followed by DELETE; missing/deleted messages retain their original wording. API `CU03_DELETE_USER_INFO_DELETE_USER_SEC_FILE_and_missing`; UI CU03 PF5. |
| SEND-USRDEL-SCREEN, RECEIVE-USRDEL-SCREEN, POPULATE-HEADER-INFO, CLEAR-CURRENT-SCREEN, INITIALIZE-ALL-FIELDS | Render shared header and protected BMS details. PF4 and a successful delete clear the input and details. UI CU00 selection and CU03 clear/delete tests. |

**Quirks retained.** PF12 is dispatched by COBOL despite being missing from the
BMS legend; the web legend includes it. An unexpected delete failure still reads
`Unable to Update User...`. As in COBOL, PF5 can delete a typed ID without a
prior Enter; no password field is present.
Deletion blocks future sign-ons; already issued E2 JWTs remain valid until
expiry.

Configured users are seeded only when the entire `user_security` table is
empty, as a bootstrap analogous to [DUSRSECJ](../../app/jcl/DUSRSECJ.jcl).
Startup does not recreate a deleted configured account while other users
remain (`CU03_DELETE_USER_SEC_FILE_doesNotReseedDeletedConfiguredAdmin`).
An empty table is treated as a bootstrap on the next startup.
